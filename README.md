# JobConnect – Online Job Portal

JobConnect is a Django-based Online Job Portal that connects Job Seekers with Employers.

## Features

- User Registration and Login
- Role-Based Access (Job Seeker and Employer)
- Job Posting and Management
- Search and Filter Jobs
- Apply for Jobs
- View Job Applications
- Update Application Status
- User Dashboard
- My Profile

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite

## Project Purpose

The main purpose of this project is to provide an online platform where job seekers can find and apply for jobs, while employers can post jobs and manage applications.
